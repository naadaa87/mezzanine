# 메자닌 서울 홈페이지 · 대관 플랫폼

메자닌 삼성·북가좌·한남·응암(오픈 예정)의 공식 홈페이지와 대관 문의·견적·예약 관리 시스템입니다.
Cloudflare Workers(정적 파일 + API)와 D1 데이터베이스로 동작하며, 빌드 과정이 없습니다.

## 구성

| 구분 | 주소 | 내용 |
| --- | --- | --- |
| 홈 | `/` | 브랜드 소개, 지점별 건물 구성 단면도, 사례, 진행 절차 |
| 지점 | `/venues`, `/venues/{지점}` | 지점 소개, 건물·층 구성, 오시는 길, 예약 현황 달력 |
| 대관 사례 | `/cases` | 지점별 행사 사례 |
| 대관 문의 | `/inquiry` | 지점·공간·일정·행사 내용을 받는 문의·견적 요청 양식 |
| 내 문의 조회 | `/my` | 접수번호로 진행 상황 확인, 견적 수락·거절, 담당자와 메시지 |
| 이용 안내 | `/guide` | 대관 절차, 유의 사항, 자주 묻는 질문 |
| 관리자 | `/admin` | 대시보드, 문의·견적·예약·고객 관리, 사이트 콘텐츠 수정, 사진 업로드, 설정 |

## 폴더

```
src/            Worker 코드 (라우터, API, 화면 템플릿)
  index.js        주소별 분기
  api-public.js   문의 접수, 내 문의 조회, 예약 현황, 사진 제공
  api-admin.js    관리자 API (로그인, 문의, 견적, 예약, 고객, 콘텐츠, 사진)
  db.js           D1 테이블 자동 생성, 콘텐츠 읽기/쓰기
  seed.js         기본 콘텐츠 (지점·사례·FAQ). 관리자에서 수정하면 D1 값이 우선
  render/         HTML 템플릿과 건물 단면도(SVG)
public/         정적 파일 (CSS, JS, 관리자 화면)
wrangler.jsonc  Cloudflare 설정 (D1 연결 포함)
```

## 배포

1. Cloudflare에서 D1 데이터베이스(`mezzanine`)를 만들고, `wrangler.jsonc`의 `database_id`에 해당 ID를 넣습니다.
2. Cloudflare **Workers & Pages → Create → Import a repository**에서 이 저장소를 연결합니다. 배포 명령은 기본값 `npx wrangler deploy`입니다.
3. 이후에는 `main` 브랜치에 푸시할 때마다 자동으로 배포됩니다.

테이블은 첫 접속 때 자동으로 만들어지므로 따로 실행할 명령이 없습니다.

## 관리자 첫 설정

배포 후 `/admin`에 처음 접속하면 관리자 계정을 만드는 화면이 나옵니다. 여기서 정한 아이디와 비밀번호가 대표 관리자 계정이 됩니다. 배포 직후 바로 만들어 주세요.

- 비밀번호는 PBKDF2로 암호화해 저장하며, 원문은 어디에도 남지 않습니다.
- 추가 관리자 계정과 비밀번호 변경은 관리자 → 설정에서 합니다.
- 새 문의 알림은 설정의 "알림 받을 주소"에 슬랙·디스코드 수신 웹훅 주소를 넣으면 켜집니다.

## 로컬 실행

```
npm install
npm run dev     # http://localhost:8787
```

로컬에서는 `.wrangler/` 안에 임시 D1이 만들어집니다.
